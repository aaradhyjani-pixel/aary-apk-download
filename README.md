# Aary Code Studio & IDE — Android Release (v1.1.0) 📱⚡

The complete, crash-proof native Android application to **write and run code directly on your Android phone or tablet**.

## 🚀 Features
- **JavaScript (ES6+) Runner**: Real in-engine JavaScript execution with live captured console output, execution timing, object inspect, and async support.
- **Python Algorithm Simulator**: Run Python code, loops, functions, lists, math, and prints directly on device.
- **HTML / CSS / JS Live Preview**: Live interactive rendering view for web components, Canvas animations, and mini apps.
- **Offline & Standalone**: Zero remote server required; operates 100% offline.
- **Preloaded Presets**: Fibonacci benchmarks, Prime Number Sieve, Canvas games, and Async Fetch examples.
- **Auto-Save**: Saves code locally in storage so your work is never lost.
